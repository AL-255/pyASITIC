    Mesh settings · distributed simulations

    Shared by LMAT, Pi models, sweeps, self-resonance and coupled analysis. Larger cells use fewer filaments and run faster. Compare finer meshes to check convergence. Browser limit: 256 filaments.     Self-resonance search · SELFRES SLOW

    Repeated distributed network solves using the original ASITIC search. Set a range around the expected resonance and inspect input reactance for a zero crossing. The native search can stop at the requested frequency resolution without verifying a crossing.

    Uses the shared mesh and native eddy settings. A reported stopping frequency may fall between evaluated samples; the final evaluated model retains its actual sample frequency.

    Three-terminal equivalent circuits · Pi / Pi2 / Pi3 / Pi4 / PiX

    Distributed filament and layered-substrate solvers. Uses the frequency above and the shared mesh settings. Eddy currents are disabled.

    Pi4 solves the device with two pad strips, then removes their capacitive contribution. Enter the pad geometry in the technology chip coordinates.

    Model metrics & two-port parameters
    Coupled windings · CALCTRANS

    Choose a transformer or balun to analyze both windings. Uses the selected frequency, CAP/LMAT mesh and eddy setting.

    The selected electrical winding is port 1; choose port 2 with Other winding above. That choice also sets the other-winding reference for Pi/CAP. Sweeps use the frequency range, point count and scale above. Values can be negative, greater than one, or undefined in the native model.

    Layered-substrate capacitance · CAP

    Original ASITIC contact-potential solver: layered Green functions, reflected FFT tables, and potential-matrix inversion. Returns the folded segment admittance matrix. Frequency and process technology are shared with the controls above.

    Contact positions must fit inside the technology chip and resolve on its FFT grid. The process file sets FFT resolution. Up to 256 contacts.

    Filament EM solver · LMAT

    Solves the original filament impedance assembly and reduction, including via corrections. The native eddy control above applies here too; substrate capacitance is separate. Mesh cell sizes are in µm.

    Uses the frequency above. Up to 256 filaments; larger cell sizes reduce the mesh. Compare meshes to check convergence.
